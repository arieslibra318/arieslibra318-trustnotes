# trustnotes

信託法規與實務｜三色重點筆記 → 簡報（生成式AI跨校聯盟作業：建立自己的 CLAUDE.md）

- `CLAUDE.md`：專案規則檔（給 Claude 讀的工作說明）
- `ideas/`：從筆記抽出的原始素材（ch01–ch21.md、chapters.json）
- `slide_notes/`：簡報大綱與待確認事項
- `presentation/`：`review.html`（複習版 93 頁）、`report.html`（報告版 17 頁）
- `assets/`：原創貓咪插圖（SVG）
- `tools/`：產生素材與簡報的 Python 腳本（`python tools/build_deck.py .`）
- `index.html`：入口頁

開啟 `index.html` 即可選擇版本；簡報可用 ← → 鍵翻頁，F 全螢幕，M 開目錄。
